HTML5

HTML5 is the latest version of HTML. It is used to create web pages and applications. It is the starting point and most fundamental language to create a website.

Syntax

<!DOCTYPE html > This tag defines the document is html

< meta charset=> - This tag sets the meta character

<html> - this tag is the root element of an html page

<head> - this tag contains meta information about the page like title scripts and style sheets elements that can be used within <head> are:

  • <title>
  • <base>
  • <link>
  • <style>
  • <meta>
  • <script>
  • <template>

<title> - This tag specifies the title for the page, content is shown in the title bar

<body> - This tag defines the document body. A container for all visible contents. What the browser displays

<h1> - This tag creates a large heading. Headings are number h1 -h6

<p> - This tag creates a paragraph
